# Gate Control Dashboard - Frontend

Modern React + Vite + Tailwind CSS dashboard for monitoring and operating the remote security gate.

---

## 1. Quick Start

### Installation:
```bash
npm install
```

### Run in Development:
```bash
npm run dev
```
Dashboard opens at: `http://localhost:5173`

### Production Build:
```bash
npm run build
npm run preview
```

---

## 2. Environment Variables (.env)

Create a `.env` file in the `frontend/` directory:
```env
VITE_API_URL=http://localhost:5000/api
```
